### Tollkit — pay-per-call tools for AI agents

Agents call a tool, pay for that one call in USDC with [x402](https://x402.org) on Base or Solana (most tools cost under a cent), and get the answer. No accounts, no API keys, and failed calls are never charged.

**Connect:** add `https://extract.tollkit.dev/mcp` to Claude, Cursor or any MCP client · [all tools and prices](https://tollkit.dev/tools) · [llms.txt](https://extract.tollkit.dev/llms.txt)

| | What agents get | From |
|---|---|---|
| 🌐 Web | any page as text from a real browser, screenshots, summaries, PDF to text, search + read | $0.002 |
| 📊 Public data | SEC filings and due diligence, US weather, FAA airport delays, geocoding, exchange rates, IP lookup | $0.002 |
| ⛓️ On-chain | wallet balances and portfolios, token prices and safety checks, transactions, a pre-trade check — Base, Ethereum, Solana | $0.002 |
| 🔎 x402 market data | the best x402 tools for a task, seller lookups, the full market dataset | $0.01 |
| 🛒 Product data | price, stock and SKU from any store page | $0.01 |
| 🔏 Proof | signed, timestamped record of what a page said | $0.25 |

**Free:** a weekly [x402 market report](https://tollkit.dev/report) on who really earns from agent payments · [Weigh Station](https://tollkit.dev/weigh-station) checks for any x402 endpoint · live [sales](https://tollkit.dev/stats) and [status](https://tollkit.dev/status) pages.
